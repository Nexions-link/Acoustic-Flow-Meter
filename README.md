# Acoustic Flow Meter — акустический счётчик объёма смеси

Статическое веб-приложение для iPhone и компьютера. Определяет длительность жужжания прибора по микрофону и вычисляет объём при заданном расходе:

`V [л] = Q [л/мин] × t [с] / 60`.

Данные микрофона обрабатываются прямо в браузере. На сервер звук не передаётся, аудиозаписи не создаются. Журнал продувок хранится в браузере, можно экспортировать CSV.

## Опубликованное приложение

Адрес GitHub Pages: https://nexions-link.github.io/Acoustic-Flow-Meter/

Исходники находятся в публичном репозитории `Nexions-link/Acoustic-Flow-Meter` в ветке `main`. GitHub Pages публикует файлы из корня ветки. Разрешите доступ к микрофону в Safari при первом запуске.

Сайт не требует собственного сервера. HTTPS на GitHub Pages обеспечивает защищённый контекст для `getUserMedia`. Настройки Pages обычно включаются в веб-интерфейсе GitHub один раз.

## Использование

1. Ввести расход смеси в л/мин.
2. Включить микрофон.
3. При остановленном приборе записать «тишину» (2 секунды).
4. Во время работы прибора записать «жужжание» (2 секунды).
5. Начать автоучёт. Сначала идёт проверка продолжительности звука. Сигналы **до 10 секунд включительно** отбрасываются без изменения суммы и журнала. Если жужжание длится **более 10 секунд**, цикл подтверждается и учитывается **полностью с момента начала**, а не с 10-й секунды. После прекращения звука цикл завершается, результаты суммируются.
6. Проверить рассчитанный объём и при необходимости экспортировать CSV.

Предварительное жужжание около 0,67 с отделяется от рабочего цикла паузой минимум 0,2 с. Подтверждённый рабочий цикл завершается после 0,7 с тишины; это время ожидания не прибавляется к объёму. Если между коротким и длинным жужжанием нет различимой паузы (меньше ~0,2 с), алгоритм может объединить звуки — для точной настройки потребуется запись реального прибора.

Есть кнопки ручного запуска/остановки для тестирования расчёта без прибора; ручные циклы не ограничены минимальными 10 секундами.

## Важные ограничения

- **Экран iPhone и вкладка Safari должны оставаться активными.** В фоне iOS может останавливать доступ к микрофону; при скрытии страницы приложение останавливает учёт.
- Это экспериментальный акустический метод определения *времени*, а не поверенное средство измерения объёма газа. Соответствие моментов жужжания фактическому потоку нужно подтвердить экспериментально.
- Резкие внешние шумы, смена позиции телефона, похожие частоты и фоновое оборудование могут вызывать ложные срабатывания. Для рабочих измерений проведите контрольную проверку точности.
- Точность распознавания зависит от частоты анализа (16 раз в секунду), устойчивости предварительного звука в течение 0,4 с, паузы 0,2 с при отсеивании короткого сигнала и задержки завершения подтверждённого цикла 0,7 с. Отсчёт времени корректируется на подтверждение начала и конца по доступным кадрам анализа.
- При смене расхода новое значение будет применено к **следующему** циклу, текущий продолжит расчёт с исходным расходом.
- Журнал хранится локально в браузере и может потеряться при очистке данных сайта.

## Проверка на компьютере

Можно запустить локальный HTTP-сервер: `python3 -m http.server 8000` и открыть `http://localhost:8000/`. Для iPhone используется опубликованный HTTPS-адрес.
